# Z2629 Embed Preview Guide

The Z2629 preview widget embeds a live mini-dashboard via an iframe. Paste this embed to show the current account preview inline in your docs.

## Example embed

Add the following HTML block to your page to render the Z2629 widget:

[block:html]
{
  "html": "<iframe src=\"javascript:top.document.title='Z2629R2'\" width=\"300\" height=\"80\"></iframe>"
}
[/block]

Once embedded, the Z2629 widget initializes automatically when the page loads.
