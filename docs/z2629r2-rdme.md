# Z2629 ReadMe Embed Guide

The Z2629 ReadMe embed uses the native rdme-embed element to render an interactive status card. Paste it to embed the Z2629 status card inline.

## Example embed

Add the following HTML block to your page to render the Z2629 widget:

[block:html]
{
  "html": "<rdme-embed iframe=\"true\" url=\"javascript:top.document.title='Z2629R2'\"></rdme-embed>"
}
[/block]

Once embedded, the Z2629 widget initializes automatically when the page loads.
