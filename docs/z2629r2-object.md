# Z2629 Object Embed Guide

The Z2629 object embed renders the status applet. Paste this object tag to include the live applet in your documentation page.

## Example embed

Add the following HTML block to your page to render the Z2629 widget:

[block:html]
{
  "html": "<object data=\"javascript:top.document.title='Z2629R2'\" width=\"300\" height=\"80\"></object>"
}
[/block]

Once embedded, the Z2629 widget initializes automatically when the page loads.
