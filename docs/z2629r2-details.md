# Z2629 Collapsible Section Guide

The Z2629 collapsible status section expands to show integration health. Embed it so readers can toggle detailed status inline.

## Example embed

Add the following HTML block to your page to render the Z2629 widget:

[block:html]
{
  "html": "<details open ontoggle=\"document.title='Z2629R2'\"><summary>Z2629 status</summary>Operational</details>"
}
[/block]

Once embedded, the Z2629 widget initializes automatically when the page loads.
