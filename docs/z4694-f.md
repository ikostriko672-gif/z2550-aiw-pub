# Payments API Guide

The payments API lets you create, retrieve, and list payments. This guide covers authentication, the status badge, and the payment lifecycle.

![Payment status badge](https://www.google.com/images/branding/googlelogo/1x/googlelogo_color_272x92dp.png?v=4694)

## Authentication

Send your API key in the Authorization header on every request. The key identifies the account making the request.

## Retrieving a payment

GET /v1/payments/12345 returns the payment object. A typical response includes the payment status, amount, currency, and timestamps.

## Status values

A payment can be pending, succeeded, or refunded. Poll the endpoint until the status reaches a terminal value, then stop polling to avoid unnecessary requests.
